Job Agent API 调试页

已删除旧接口，只保留新接口调用。结果文本区域、复制、清空功能保留。

不要带最后的斜杠。

1. 发现公司 Careers 职位链接

POST /api/job-imports/company-careers/discover：只扫描职位详情页链接，不导入数据库。

2. 批量解析 Careers 职位并入库

POST /api/job-imports/company-careers/jobs：扫描职位详情页，解析后写入数据库，重复导入不重复插入。

3. 最近导入职位

GET /api/jobs/latest：查询数据库里最近创建/最近导入的职位。

4. 轻量职位搜索

GET /api/jobs/search：按 keyword、公司、工作模式、职级、分析状态快速筛选。

5. 复杂职位搜索

POST /api/jobs/search：多条件组合搜索，支持国家、城市、用工类型、发布时间、分页 offset。

6. 单条职位 AI 分析

POST /api/job-analyses/{jobId}/run：对某一条职位执行 AI 分析。

7. 根据用户画像匹配职位

POST /api/job-matches/search-by-profile：根据简历、技能、求职目标和偏好匹配职位。

会自动转换成数组：["Unity", "C#", "AI", "WebGL"]
